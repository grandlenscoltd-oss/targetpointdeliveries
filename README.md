## 📸 Overview

This is a fully responsive, conversion-focused single-page website built to market Target Point Deliveries to both B2B clients and individual customers in Nairobi. The design is built around one goal: turn every visitor into a call or WhatsApp order.

---

## ✨ Features

- **Dark navy hero section** with animated floating delivery card and live ETA mockup
- **Animated stat counters** — scroll-triggered (500+ deliveries, 20 zones, 50+ businesses)
- **6-service showcase** with hover interactions and featured card treatment
- **3-step "How it works"** section with interactive hover states
- **Why Choose Us** — full dark section with sliding feature cards
- **Transparent pricing** — 3-zone pricing cards with M-Pesa Till prominently displayed
- **Testimonials** from real business clients
- **Smart enquiry form** — auto-composes a pre-filled WhatsApp booking message
- **Floating WhatsApp button** — always visible on every scroll position
- **Scroll-reveal animations** on all sections
- **Mobile-first responsive** — optimised for phone users (your primary audience)
- **Active nav link highlighting** as you scroll through sections

## 🚀 Deployment (Netlify)

### Option 1 — Drag & Drop (easiest)
1. Go to [netlify.com](https://netlify.com)
2. Click **Add new site → Deploy manually**
3. Drag the project folder onto the upload area
4. Site is live in under 30 seconds

### Option 2 — Connect via GitHub (recommended for auto-deploy)
1. Push this repo to GitHub ✅ *(already done)*
2. Go to [netlify.com](https://netlify.com) → **Add new site → Import from Git**
3. Select this repository
4. Leave build settings blank (no build command needed — static site)
5. Click **Deploy site**

Every future `git push` to `main` will automatically redeploy the live site.
